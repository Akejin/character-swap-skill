# 移形换影

> IDENTITY FROM THE SAMPLE. PERFORMANCE FROM THE SCENE.

移形换影是一个为 Codex 编写的双参考图人物替换 Skill。给定一张**场景照片**和 1-2 张**人物样片**，它把场景中的人物替换成样片中的人——而且把「人从哪里来」和「怎么演」拆开处理：

- **样貌**（整张脸、发型、服饰、身材、年龄感、性别呈现）**完全来自人物样片**，不与场景原人物混合、不折中；
- **表演**（表情、视线方向、头部朝向、肢体动作、手势）与**面部光影**（光向、高光、阴影、色温）**逐项复刻场景原人物**——替换前先识别原图人物的视线目标，替换后看向完全相同的位置；
- **场景其余一切**（背景、光线、他人、道具、场景文字）逐像素保留。

最终效果：像样片里的人，自然地在原场景里，做原人物正在做的事。

---

## 它解决什么问题

```text
场景照片（图1）+ 人物样片（图2/图3）  →  一次生成：同一场景，换人上场
```

普通「图生图换脸」最常见的失败是**混合脸**——五官被两个人平均，越看越不像任何人。移形换影用一份固定的三段式指令直接约束出图模型：

| 来源 | 提供什么 |
| --- | --- |
| **人物样片（图 2 起）** | 整张脸、发型、服饰、身材、年龄感、性别——「这是谁」 |
| **场景照片（图 1）** | 表情、视线目标、头部朝向、肢体动作、脸上的光影——「在做什么」 |

替换只发生在指定人物身上：手挡脸还是挡脸，杯遮口还是遮口，侧脸依旧侧脸。

## 两种使用模式

| | 单人物 | 双人物 |
| --- | --- | --- |
| **输入** | 图 1 场景 + 图 2 人物样片 | 图 1 场景 + 图 2、图 3 两张人物样片 |
| **替换对象** | 场景中最主要的人物 | 默认图 2 → 第一/最显眼人物，图 3 → 第二人物 |
| **多人场景** | 在文字里说明替换哪一个 | 在文字里说明「谁替换谁」 |

它适合这样的请求：

```text
用 $character-swap-v1-0 把这张照片里左边的人换成第二张照片里的人，
其他一切保持不变。

用 $character-swap-v1-0 做双人物替换：图 2 替换穿白衬衫的男士，
图 3 替换坐在右侧的女士。
```

## 开始使用

### 安装

克隆仓库，把 Skill 复制到 Codex Skills 目录：

```bash
git clone https://github.com/Akejin/character-swap-skill.git
mkdir -p ~/.codex/skills
cp -R character-swap-skill/skills/character-swap-v1-0 ~/.codex/skills/
```

如果 Skill 没有立即出现，请重启 Codex。

### 使用

1. 准备一张场景照片（含被替换人物）和 1-2 张人物样片。
2. 上传图片并调用 `$character-swap-v1-0`；可附加文字说明替换映射或服饰细节。
3. 返回替换完成的单张照片和一段简短创作说明。

## 关于照片

Skill 只把用户提供的场景照片与人物样片作为当前替换任务的参考。除非用户明确要求，不应浏览、分享、另行上传或保存这些照片，也不将人物样片用于本次替换之外的任何用途。有关具体处理规则，请阅读 [Skill 文档](skills/character-swap-v1-0/SKILL.md)。

## 更多 AI 图像玩法

如果你想继续玩 AI 图像，可以试试 **Imagin AI**（[www.imaginai.art](https://www.imaginai.art)）——一个**多风格技能通用文生图网页应用**：在网页上输入文字或导入参考图，选择风格技能，即可生成对应风格的海报/艺术作品，不用本地部署。
