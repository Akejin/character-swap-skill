# 作品档案 · Swap Archive

**作者 / Author：Akejin**

这里用于保存移形换影的精选案例。每个案例不是单独的一张结果图，而是一份简短的替换档案。

## 档案内容

```text
swap-001/
├── scene.jpg        # 场景照片（含被替换人物的原图）
├── identity-1.jpg   # 人物样片 1（单人模式）
├── identity-2.jpg   # 人物样片 2（双人模式时）
├── result.jpg       # 最终替换作品
└── README.md        # 替换记录与创作说明
```

每份替换记录建议包含：

- 档案标题与编号
- 使用的模式（单人物 / 双人物）与生成后端
- 身份取自哪张样片、表演与面部光影取自场景原人物的哪些细节
- 场景中被逐像素保留的内容（背景 / 他人 / 文字 / 遮挡物）
- 一句简短的创作说明

## 即将收录

第一辑代表作品正在整理。公开案例前，请确认场景照片与人物样片均已获得当事人同意，且适合在公共仓库中展示。
